# 无障碍访问测试文档

## WCAG 2.2 AA 合规性测试

### 测试工具

- **自动化测试**: axe-core, Lighthouse, WAVE
- **手动测试**: 键盘导航, 屏幕阅读器 (NVDA, VoiceOver)
- **颜色对比**: WebAIM Contrast Checker

---

## 1. 感知性 (Perceivable)

### 1.1 文本替代

**测试用例**: 所有非文本内容有文本替代

| 元素 | 预期 | 测试结果 |
|------|------|----------|
| Logo 图片 | 有 alt 属性 | ⬜ |
| 图标按钮 | 有 aria-label | ⬜ |
| 装饰性图片 | alt="" 或 aria-hidden | ⬜ |
| 图表 | 有详细描述 | ⬜ |

### 1.2 颜色对比度

**测试用例**: 文本与背景对比度 ≥ 4.5:1

| 元素 | 预期对比度 | 实际对比度 | 测试结果 |
|------|------------|------------|----------|
| 正文文本 | ≥ 4.5:1 | | ⬜ |
| 标题文本 | ≥ 3:1 | | ⬜ |
| 链接文本 | ≥ 4.5:1 | | ⬜ |
| 按钮文本 | ≥ 4.5:1 | | ⬜ |
| 占位符文本 | ≥ 4.5:1 | | ⬜ |

### 1.3 文本大小调整

**测试用例**: 文本可放大至 200% 不丢失内容

- [ ] 页面在 200% 缩放下正常显示
- [ ] 无水平滚动条（320px 宽度）
- [ ] 所有内容可访问
- [ ] 功能正常工作

## 2. 可操作性 (Operable)

### 2.1 键盘可访问

**测试用例**: 所有功能可通过键盘访问

| 功能 | 预期 | 测试结果 |
|------|------|----------|
| 页面导航 | Tab 键 | ⬜ |
| 链接激活 | Enter 键 | ⬜ |
| 按钮激活 | Enter/Space | ⬜ |
| 下拉菜单 | Enter/Space/方向键 | ⬜ |
| 模态框 | Escape 关闭 | ⬜ |
| 滑块 | 方向键调整 | ⬜ |

### 2.2 焦点可见

**测试用例**: 焦点指示器清晰可见

- [ ] 所有交互元素有焦点样式
- [ ] 焦点顺序合理（从左到右，从上到下）
- [ ] 焦点不被裁剪或遮挡
- [ ] 自定义焦点样式符合对比度要求

### 2.3 焦点陷阱

**测试用例**: 模态框和弹出框有焦点陷阱

- [ ] 打开模态框时焦点移到模态框内
- [ ] Tab 键循环在模态框内
- [ ] Escape 键关闭模态框
- [ ] 关闭后焦点返回触发元素

### 2.4 跳过导航

**测试用例**: 有跳过导航链接

- [ ] 页面顶部有"跳转到主要内容"链接
- [ ] 链接可键盘访问
- [ ] 点击后焦点移到主内容区

- [ ] 导航菜单位置一致
- [ ] 导航项目顺序一致

### 3.3 表单标签

| 表单元素 | 预期 | 测试结果 |

| 下拉选择 | 有 label 或 aria-label | ⬜ |

| 单选按钮 | 有关联的 label | ⬜ |

### 3.4 错误提示

**测试用例**: 错误提示清晰且可访问
