## Why

个人投资者通常能获得行情、新闻和技术指标，却很难把这些信息转化为一份可执行、可解释、可复盘的交易计划。现有草案覆盖了搜索、模型和建议，但没有定义数据时点、回测真实性、组合风险、建议有效期和合规边界，容易产生未来函数、过拟合和“保证收益”的错误预期。

本变更建设一款“量化研究与交易计划辅助软件”：用户输入证券代码和自身约束后，系统整合可追溯数据，运行经验证的策略与风险模型，输出分阶段、带触发条件的计划。系统优化风险调整后的决策质量，不承诺达到目标收益，也不代替持牌投资顾问或用户本人作出决策。

## What Changes

- 建立证券主数据与多源、带时间戳和来源的数据检索，明确数据新鲜度和降级状态。
- 以 OCI Generative AI Responses API 上的 xAI Grok 4.3 / Grok 4.20 Multi-Agent 建立实时情报层，组合 X Search、公共 Web Search 与 Code Interpreter，分开呈现 X 原文和公共开放信息，并保留引用、查询窗口、实际工具和模型版本。
- 增加“实时信息检索”工作台，支持主题、关键词/别名、日期范围、来源通道和最大条数；所有结果明确为尽力覆盖，不宣称获得 X 或公共网络全量数据。
- 增加“成员国与项目风险情报”工作台，持续监测政治、社会、债务、环境和声誉地面信号，输出带引用的直接风险简报、事件时间线与人工复核动作。
- 增加“地缘政治与融资影响”工作台，围绕项目管道、联合融资、成员借贷意愿、可行性和风险转移构造可验证的传导链与基准/压力/机会情景。
- 建立投资者画像、目标收益、期限、资金、持仓、流动性和最大可承受回撤等约束；在输入不完整或目标不可行时拒绝生成个性化计划。
- 建立统一的研究、回测、走样本外验证、模拟跟踪和模型注册流程，显式建模手续费、滑点、停牌、涨跌停、复权和公司行动。
- 建立时点资产池与轻量特征注册表，使研究、训练、正式回测和实时模拟使用同一特征定义，并检测 offline/online skew。
- 为每项策略预注册研究协议并记录全部试验；大量调参时使用多重检验修正，避免只报告“试出来的最好结果”。
- 采用不可变模型版本、环境隔离、`champion`/`challenger` 别名和 shadow 比较；建议生成时必须把别名解析并固化为具体版本。
- 建立组合级建议引擎，把信号、风险预算、持仓约束和市场状态合成为“观察—试仓—加减仓—退出”的条件计划。
- 建立任务导向的页面体系与可恢复操作流程，把普通用户的“研究—计划—模拟跟踪”和研究员的“假设—实验—回测—shadow—审批”明确分区。
- 建立跨模块统一的可读性字号契约：全局正文保持清晰基线，卡片正文、说明、状态和表格按层级放大，紧凑辅助标签设置下限；字号变化通过自然增高、换行、单列折叠或可达滚动适配，不以文字覆盖或裁切换取信息密度。
- 每条建议展示依据、假设、置信度、数据截止时间、适用期限、失效条件和风险情景；禁止使用“保证收益”等表述。
- 将大模型限制在检索增强、信息摘要和解释层；订单方向、规模和风控必须来自版本化的确定性规则或已批准模型。
- 将社交媒体公开表述与已验证交易披露严格区分；大 V 动态不得单独触发行动建议，不实现自动跟单。
- 建立审计、模型治理、人工审批、权限、隐私与合规门禁；MVP 仅研究和模拟，不连接真实券商执行。
- 架构从过早微服务调整为模块化单体加异步任务，保留数据源、模型和执行适配器边界，待负载或团队规模证明需要时再拆分。

## Capabilities

### New Capabilities

- `stock-input`: 证券唯一识别、歧义确认、批量输入、自动补全和搜索历史。
- `data-search`: 多源市场/基本面/新闻数据聚合、时点查询、来源追踪与数据质量状态。
- `model-training`: 特征、策略、模型、回测、走样本外验证、模拟跟踪和模型注册。
- `recommendation-engine`: 组合级风险预算、分阶段条件计划、解释、失效与再评估。
- `user-config`: 投资目标、期限、风险承受能力、资金和组合约束的采集、适当性检查与版本管理。
- `governance`: 合规门禁、模型审批、审计留痕、权限、隐私、监控和应急停用。
- `advisor-workflow`: 角色化导航、证券研究工作台、分步计划生成、异步任务状态、计划版本比较、通知和无障碍交互。
- `open-platform`: 租户与工作区上下文、成员角色、客户化品牌、策略包、扩展清单和多形态部署契约。
- `institutional-intelligence`: X/公共开放信息检索、项目级实时风险与舆情监测、地缘融资影响推演、引用账本、工具降级审计、直接判断、情景假设和人工决策门禁。

## Impact

- **产品**：新增研究工作台、画像向导、策略实验室、计划详情、组合风险和复盘页。
- **机构情报**：新增 X/公共网页实时信息检索、项目风险扫描、持续监测清单、地面信号时间线、五维风险雷达、融资传导链和多情景战略直读页。
- **交互**：新增全局证券搜索、今日待办、分步计划向导、证据抽屉、后台任务中心、通知收件箱及页面级健康/陈旧/拒绝状态；当前产品壳同时采用 15px 正文基线、9px 紧凑标签下限和面向卡片内容的分层字号，并保留手机、平板、电脑响应式重排。
- **后端**：新增数据接入、特征/回测、建议编排、治理审计和异步任务模块。
- **数据**：新增证券主数据、双时态市场数据、数据血缘、画像版本、实验、模型、建议快照和审计事件。
- **研究基础设施**：新增时点资产池、特征定义/特征集版本、试验账本、确定性事件日志和模型别名；是否采用 LEAN、Qlib 或自研轻量引擎由技术验证决定。
- **外部依赖**：需要经过许可与成本评估的行情、基本面、公司行动和新闻数据；MVP 不把免费网页抓取作为生产数据源。
- **OCI / xAI**：新增 OCI Responses API、X Search、Web Search 兼容探测、Code Interpreter、IAM、区域/配额、成本和第三方模型数据边界依赖；模型 ID 由运行时配置解析，工具不兼容时只对明确的 400/422 校验错误执行可审计降级。
- **合规**：面向中国境内公众上线前必须完成证券投顾、生成式 AI、个人信息、数据许可和内容标识的专项法律评估；免责声明不能替代所需资质。
- **兼容性**：无现有生产 API 或数据需要迁移。
- **开放平台**：新增平台清单 API 和工作区级产品上下文；生产启用机构租户前必须完成服务端数据隔离、企业身份、租户密钥和用量配额。

## Success Metrics

- 100% 建议可追溯到数据快照、策略/模型版本、画像版本和规则版本。
- 100% 回测通过时点正确性、成本模型、样本外和基准比较检查后方可注册。
- 100% 正式实验登记研究协议与完整试验次数；达到配置阈值时执行 Deflated Sharpe 或等价的多重检验修正。
- 100% 训练集通过 point-in-time join；关键特征的训练/模拟一致性检查通过后才允许生成计划。
- 100% 建议引用具体不可变模型版本，不把可变别名作为审计依据。
- 100% Grok 派生的实时事实或趋势包含可访问引用、查询时窗、账号范围、OCI request/response 标识、模型和提示版本；无引用结果只能标记为 `unverified`。
- 100% 项目风险简报区分事实、媒体转述、公开观点与模型推断，并为动作建议提供负责人、时限和可观察触发条件。
- 100% 地缘融资推演显式列出传导机制、关键假设、未知项和早期信号；不得把模型推断表述为成员国或机构的正式立场。
- 0 条行动建议仅由社交情绪、单一大 V 表述或未经证实的“买入/卖出”声明触发。
- 新用户可在一个可恢复流程内完成画像、证券研究和首份模拟计划；中断后返回原步骤且不丢失已确认输入。
- 100% 关键页面显示证券/组合上下文、`as_of`、时区、数据健康和当前模式；后台任务离开页面后仍可查询、取消和恢复查看。
- 默认缩放下，当前产品壳所有显式可见文字不低于 9px，主要卡片正文/说明保持在约 10–13px 层级；字号放大后核心卡片、表格和长文本结果不得出现裁切、覆盖或不可达内容。
- 核心流程达到 WCAG 2.2 AA，键盘、屏幕阅读器、200% 缩放和 320 CSS px reflow 验收通过。
- 100% 计划包含风险预算、失效条件、有效期和不利情景；禁止项命中时不生成建议。
- MVP 关键查询 p95 小于 2 秒；异步计划生成 p95 小于 60 秒；失败任务可安全重试。
- 模拟期至少覆盖一个预设观察窗口，实时模拟与同期样本外回放差异可解释后才考虑实盘连接。
