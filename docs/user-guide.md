## 系统概述

量化交易建议系统是一款基于人工智能的股票分析和交易建议工具。系统整合多源数据，运用量化模型和大语言模型，为用户提供专业的股票分析和交易建议。

### 主要功能

- 📊 **股票查询**: 支持美股、港股、A股等多市场股票查询
- 💡 **交易建议**: 基于量化模型生成买卖建议
- 🤖 **模型管理**: 训练和优化量化交易模型
- 📈 **投资组合**: 管理和优化投资组合
- ⚙️ **个性化配置**: 根据风险偏好定制建议

### 重要声明

⚠️ **免责声明**: 本系统提供的所有信息仅供参考，不构成任何投资建议。投资有风险，入市需谨慎。

## 快速开始

### 1. 注册/登录

1. 访问系统首页
2. 点击"注册"创建账户

## 股票查询

### 单股票查询

1. 导航到"股票查询"页面
2. 在搜索框中输入股票代码（如 AAPL、600519.SH）
3. 按回车键或点击搜索按钮
4. 查看股票详细信息

### 批量查询

1. 切换到"批量查询"模式
2. 输入多个股票代码，用逗号或换行分隔
3. 点击"批量验证"按钮
4. 查看验证结果

### 自动补全

输入至少2个字符后，系统会自动显示匹配的股票建议：
- 输入 "AA" → 显示 AAPL, AMZN 等
- 输入 "600" → 显示 600519.SH 等

### 搜索历史

系统会自动保存您的查询历史：
- 点击搜索框查看历史记录
- 点击历史项快速查询
- 可清空历史记录

## 交易建议

### 生成建议

1. 导航到"交易建议"页面
2. 输入股票代码
3. 点击"生成建议"按钮
4. 等待系统分析完成

### 理解建议

每个建议包含以下信息：

| 字段 | 说明 |
|------|------|
| 建议 | 买入/卖出/持有 |
| 置信度 | 0-100%，表示建议的可信度 |
| 风险等级 | 低/中/高/极高 |
| 目标价 | 预期达到的价格 |
| 止损价 | 建议止损的价格 |
| 分析理由 | 详细的分析说明 |

### 比较建议

1. 输入多个股票代码
2. 点击"比较建议"
3. 查看对比结果
4. 系统会高亮最佳建议

### 生成交易计划

1. 点击"生成交易计划"
2. 按照向导完成配置：
   - 选择股票
   - 设置投资目标
   - 评估风险承受能力
   - 配置计划参数
3. 查看生成的分阶段计划

## 模型管理

### 训练新模型

1. 导航到"模型管理"页面
2. 点击"训练新模型"
3. 选择模型类型：
   - **线性回归**: 简单快速
   - **随机森林**: 鲁棒性好
   - **XGBoost**: 性能优异
   - **LSTM**: 适合时间序列
4. 配置超参数
5. 点击"开始训练"

### 模型评估

训练完成后，系统会显示模型性能指标：

- **准确率**: 预测正确的比例
- **精确率**: 预测为正的样本中实际为正的比例
- **召回率**: 实际为正的样本中被预测为正的比例
- **F1分数**: 精确率和召回率的调和平均

### 模型审批

1. 训练完成的模型需要审批
2. 管理员在"模型治理"页面审批
3. 审批通过后可部署使用

### 模型部署

1. 在模型列表中选择已审批的模型
2. 点击"部署"
3. 选择部署环境
4. 配置流量分配

## 常见问题

### Q: 股票代码格式是什么？

A: 系统支持多种格式：
- 美股: AAPL, MSFT, GOOGL
- 港股: 0700.HK, 9988.HK
- A股: 600519.SH, 000858.SZ

### Q: 建议的置信度是什么意思？

A: 置信度表示系统对建议的可信程度：
- 80-100%: 高置信度
- 60-80%: 中等置信度
- 0-60%: 低置信度

### Q: 如何提高建议准确性？

A: 
1. 完善用户配置（投资目标、风险偏好）
2. 使用最新的市场数据
3. 结合多个指标分析
4. 定期重新训练模型

### Q: 模型训练需要多长时间？

A: 取决于模型类型和数据量：
- 线性回归: 1-5 分钟
- 随机森林: 5-15 分钟
- XGBoost: 10-30 分钟
- LSTM: 30-60 分钟
